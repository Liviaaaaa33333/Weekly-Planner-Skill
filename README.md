# Some for Claude

讓 Claude 更好用的一些 skill（技能）。這些都是非官方專案，和 Anthropic 沒有合作或背書關係。
Some skills that help Claude work better for you. These are unofficial projects, not affiliated with or endorsed by Anthropic.

## Skills

| Skill | 說明 | Description |
| --- | --- | --- |
| [週行程排程助理 Weekly Planner](weekly-planner/) | 以 ADHD 的需求為出發點，把課表、截止日和生活小事排成「幾點做什麼」的每週行程，寫進 Google 日曆，並用互動式頁面和排程任務每天幫你調整。 | Designed around ADHD needs: turns classes, deadlines and errands into a time-blocked weekly plan, writes it to Google Calendar, and adjusts it daily with an interactive page and scheduled tasks. |

每個 skill 的資料夾裡都有自己的 README、完整教學和安裝檔。
Each skill's folder has its own README, full guide and installable zip.
