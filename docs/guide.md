## 1. 這個專案是什麼

這是一個以 Claude 為基礎的 skill（技能），把 AI 助理和日程安排結合在一起。它用 Claude 本身的兩個功能當基石：

- **排程任務：** 讓 Claude 在固定時間自己醒來，每週傳下週行程草稿給你確認，每天檢查你留下的變動。
- **互動式頁面：** 一個只屬於你的網頁，顯示「現在該做什麼」、本週行程、截止日倒數，做完就打勾。

再加上 Google 日曆連接器，行程會出現在你的手機日曆裡並準時提醒。

它以 ADHD 的需求為出發點設計：目標是給很難自己安排時間的人，一種過有條理生活的可能性。任何覺得時間很難自己分配的人也都能用。

這個專案最初是為了作者自己的日常需要而做，實際用過一段時間後，整理成任何人都能設定的公開版本。它不是 Anthropic 的官方產品。

## 2. 為什麼這樣設計

很多時間管理工具假設你會自己決定什麼時候做什麼。對 ADHD 的人來說，難的往往正是這一步：知道有哪些事要做，卻不知道從哪一件開始、什麼時候開始、要做多久。這個 skill 的每個設計都針對這些常見的困難：

| 常見的困難 | 這個 skill 怎麼做 |
| --- | --- |
| 不知道先做哪件事 | 依你設定的優先順序排好，直接告訴你「幾點做什麼」，不給選項清單 |
| 對時間長短沒有感覺 | 每件事都有預估時間，每週問你「偏多／剛好／偏少」再調整 |
| 大任務不知道怎麼開始 | 報告、申請拆成一段一段做得完的小步驟，從截止日往回推 |
| 容易排太滿，一天崩掉整週跟著垮 | 每天專注時段有上限，每週固定留三成空白 |
| 小事最容易忘，代價卻最大 | 行政事項（報名、繳費、請假信）永遠最優先、越早越好 |
| 忘了現在該做什麼 | 頁面最上方的「現在該做」卡片，打開就知道 |
| 沒做完會自責，然後乾脆放棄 | 沒完成的事不評價，只重新排到之後的空檔 |
| 突然有動力提前做完 | 空出來的時間，自動拿去排後面的事 |
| 每週都要重新想一次 | 每週固定時間自動傳草稿，你只要回覆確認 |

這些設計參考的是常見的生活困難，不是醫療建議，也不能取代診斷或治療（見第 15 章）。

## 3. 開始前要準備什麼

| 項目 | 是否必要 | 說明 |
| --- | --- | --- |
| Claude 付費方案（Pro、Max、Team、Enterprise） | 自動功能必要 | 排程任務只有付費方案有。免費方案也能設定、排行程、用頁面，只是每週要自己開對話說「排下週」 |
| 開啟「Code execution and file creation」 | 必要 | 在 Settings → Capabilities 打開，上傳 skill 需要這個功能 |
| Google 帳號與 Google Calendar 連接器 | 建議 | 把行程寫進日曆並設提醒。只支援 Google 日曆 |
| 課表、課綱（syllabus）或班表 | 建議 | 截圖或 PDF 都可以，Claude 會讀出每週進度與考試日期 |

Team 或 Enterprise 方案：組織管理員要先在 Organization settings 允許使用 skill。

## 4. 安裝 skill

1. 到 GitHub 專案的 `dist/` 資料夾，下載 `weekly-planner-for-everyone-zh.zip`（中文說明）或 `weekly-planner-for-everyone-en.zip`（英文說明）。兩個功能相同，裝一個就好。**下載後不要解壓縮。**
2. 在 claude.ai 或 Claude 桌面 App，打開 **Settings → Capabilities**，確認 **Code execution and file creation** 已開啟。
3. 打開 **Customize → Skills**，點 **＋** → **Upload a skill**，選剛才的 zip。
4. 確認清單裡的 `weekly-planner-for-everyone` 是開啟狀態。

選單名稱可能隨 Claude 介面更新而改變，找不到時請參考 [Claude 說明中心：Use Skills in Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude)。

## 5. 連接 Google 日曆

不想把行程寫進日曆可以跳過這一章，行程會只顯示在頁面上。

1. 在 claude.ai 打開 **Customize → Connectors**。
2. 找到 **Google Calendar**，點 **Connect**。
3. 登入要放行程的 Google 帳號，同意 Claude 存取日曆。
4. 回到 Connectors，確認 Google Calendar 顯示 **Connected**。

**減少「允許」提示：** Claude 每次用到日曆工具都可能問你要不要允許。可以在 Connectors 點進 Google Calendar，把 **Tool permissions** 設成 **Always allow**；或在對話中跳出提示時選 **Always allow**。

新增連接器目前建議在電腦上操作。在電腦上連好之後，手機 App 也能用。

參考：[Use Google Workspace connectors](https://support.claude.com/en/articles/10166901-use-google-workspace-connectors)。

## 6. 第一次設定

開一個新對話，輸入「幫我設定週行程排程助理」。Claude 會先說明需要付費方案才有自動功能，然後問你要哪一種設定：

- **快速設定（約 5 分鐘，建議）：** 只問四件事，其他先用預設值。
- **完整設定（約 20–30 分鐘）：** 一次講清楚通勤、專注時段、優先順序、提醒、例行事項、長期專案。

### 快速設定的對話範例

> **Claude：** 先問四件事就能開始：
> 1. 怎麼稱呼你？你在哪個時區？要不要把行程寫進 Google 日曆？
> 2. 請上傳課表或固定行程（截圖、課綱、班表都可以）。
> 3. 每天最早幾點開始排、最晚排到幾點？
> 4. 目前已知的截止日、考試、約診有哪些？
>
> **你：** 叫我小安，台北時間，要寫進 Google 日曆。課表如附件。每天 9 點到 23 點。10/9 中午交換學生申請截止，10/13 國關期中報告，11/4 統計期中考。
>
> **Claude：** 我整理一下：……（列出課表、截止日，以及用了哪些預設值）這樣可以嗎？
>
> **你：** 可以。

確認後，Claude 會：

1. 建立你的週行程頁面。
2. 排出本週剩下的日子，給你看表格，你確認後寫進日曆。
3. 把未來 4 週的重大截止日寫成全天活動。
4. 建立兩個排程任務：每週確認（預設週日 20:00）和每日檢查（預設 08:00）。

**預設值：** 專注工作排在晚上、每天最多 3 段、每段 25–50 分鐘、中間休息 20 分鐘、每週留三成空白、優先順序「行政＞截止＞閱讀＞預約＞小事」、每天檢查 1 次留言、週中有變動就直接改好再告訴你。之後隨時可以改（第 11 章）。

**課綱小技巧：** 上傳每門課的課綱 PDF，Claude 會把每週要讀的章節整理進「課堂訊息」分頁，並自動排課前閱讀。課綱沒寫清楚的地方會標「待確認」，不會自己猜。

## 7. 排程任務：自動確認與檢查

排程任務是這個專案能「自己動起來」的關鍵，需要付費方案。它們在雲端執行，電腦關機或 App 沒開也會照常執行。

### 兩個任務在做什麼

**每週確認（預設週日 20:00）**
1. 讀你的頁面，把上週沒做完的事滾進下週。
2. 排出下週草稿，傳給你：一句話總覽、逐日表格、未來三週的重大截止日。
3. 只問兩題：下週有沒有新的作業、約診或時間不固定的行程？上週的預估時間偏多、剛好還是偏少？
4. 你回覆確認後，才寫進日曆。

**每日檢查（預設 08:00，一天 1 次）**
- 處理你在「告訴 Claude」留下的新留言。
- 處理提前完成的事，把空出的時間拿來排後面的事。
- 有改動就傳一兩句話告訴你；沒事就不打擾你。

### 打開「自動核准」（很重要）

排程任務執行時沒有人在旁邊按「允許」。如果任務的核准模式是手動，它會停在第一個需要允許的步驟。

1. 在 Claude 左側欄點 **Scheduled**，找到兩個週行程任務。
2. 打開任務的設定，把核准模式改成 **Automatically approve**。
3. 兩個任務都要設定。

在這個模式下，Claude 仍會先檢查每個動作是否安全才執行。Team 或 Enterprise 方案可能被管理員關閉這個選項，這時請改成每週自己開對話說「排下週」。

### 通知

任務跑完會傳通知給你。請在手機的系統設定裡允許 Claude App 的通知，每週確認的草稿才不會漏看。直接點通知就能回到那次任務的對話回覆。

### 在 Scheduled 裡還可以

- **手動執行：** 想馬上重排，可以在任務上選立即執行。
- **暫停：** 放假不想被打擾時先暫停，之後再恢復。
- **看紀錄：** 查看過去每次執行的結果，任務沒反應時可以先看這裡（第 12 章）。

參考：[Schedule recurring tasks](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork)。

## 8. 每天怎麼用

### 看頁面

打開週行程頁面，最上方是「現在該做」卡片：現在這格要做什麼、做到幾點、接下來兩件事。下面有六個分頁：

| 分頁 | 內容 |
| --- | --- |
| 本週 | 依日期列出每個時段。今天放最上面並醒目標示，接著是之後的日子，已經過去的日子會移到最下面。做完就打勾；上課和通勤不用勾 |
| 截止日 | 最上方可以新增截止日；下方依日期排序並倒數天數，七天內的會標紅；寫錯可以刪除 |
| 例行事項 | 回診、剪頭髮、每月繳費這類固定事項，和下一次的日期 |
| 課堂訊息 | 課表、每門課下次要讀什麼；老師改過的進度會標「更新」 |
| 告訴 Claude | 留言框，寫下任何變動；還沒處理的留言可以刪除 |
| 規則 | 你的設定摘要 |

![本週分頁](screenshots/week-zh-phone.png)

### 跟 Claude 說變動

在任何對話直接說，或寫在「告訴 Claude」分頁都可以。寫在頁面的留言會在下一次每日檢查時處理。

- 「新作業：讀書心得 10/21 交」
- 「週四的課改到 21:00」「下週牙醫改到週五」
- 「以後每週運動三次」
- 「老師說下週改上第五章」「10/21 停課」「期中考改到 11/19」
- 「現在該做什麼？」
- 「今天好累，下午的事往後挪」

### 打勾

做完就在頁面打勾。「本週」和「截止日」會互相同步：勾掉「寄推薦信」，截止日那邊的推薦信也會變成完成。

**提前做完也要打勾。** 原本的時段還沒到就完成時，下一次檢查會把那段時間拿去排後面的事，日曆上的活動標題會加上「✅」並取消提醒。

### 刪除寫錯的項目

截止日或留言不小心寫錯、重複了，可以在頁面直接刪掉，不用等 Claude 處理：

- **截止日：** 每一筆右側、倒數天數下方有「刪除」。
- **告訴 Claude：** 只有「待處理」的留言可以刪。「已排入」的已經處理過，刪掉也不會撤回改動；要改的話，再留一則新的說明就好。

按一次「刪除」會變成紅底的「確定刪除？」，4 秒內再按一次才會真的刪掉，沒按就自動恢復，避免在手機上誤觸。刪掉的項目會直接從資料裡移除，頁面上不留任何紀錄，**刪除後無法復原**。

最好趁 Claude 還沒排程前刪。如果截止日已經被排進行程，下一次檢查時 Claude 會把日曆上對應的全天活動和專為它排的準備時段一起清掉，並告訴你一聲。

## 9. 找回與保護你的週行程頁面

- **找回頁面：** 左側欄的 **Artifacts**，或直接到 [claude.ai/artifacts](https://claude.ai/artifacts)，找標題含「週行程」的頁面。也可以直接問 Claude「給我週行程頁面的連結」。
- **誰看得到：** 頁面預設只有你看得到。上面有你的課表、行程和約診，**不建議**用 Share 設成「Anyone with the link」。
- **資料存在哪：** 行程資料存在頁面自己的資料庫（上限 20 MB，一般使用好幾年都用不完），不在對話裡，所以換對話、換裝置都不會遺失。
- **換裝置：** 在任何登入同一個 Claude 帳號的裝置打開同一個連結就好。

## 10. 手機上使用

### 把頁面做成 iPhone 網頁 App

1. 用 **Safari** 打開週行程頁面，並登入 Claude。
2. 點網址列旁的「⋯」或分享按鈕，選 **分享** → **加入主畫面**。
3. 取個好認的名字，例如「週行程」；**以網頁 App 打開** 保持開啟，點 **加入**。
4. 第一次從主畫面打開時，可能要在裡面再登入一次 Claude。

按鈕名稱會隨 iOS 版本略有不同。Android 可以用 Chrome 的「加到主畫面」。

### 在 Apple 行事曆看到 Google 日曆

- **iPhone：** 設定 → App → 行事曆 → 行事曆帳號 → 加入帳號 → Google，登入後打開「行事曆」。
- **Mac：** 系統設定 → Internet 帳號 → 加入帳號 → Google，勾選「行事曆」。

Apple 行事曆會用同一種顏色顯示整個 Google 日曆，看不到 Claude 設的分類顏色。Google 日曆的提醒同步過去後不一定會響；沒響的話，可以安裝 Google 日曆 App 並開啟通知。

## 11. 修改設定與使用額度

### 隨時用說的改設定

| 你想要 | 跟 Claude 說 |
| --- | --- |
| 改可排時間 | 「以後最晚排到 22:00」 |
| 改專注時段 | 「我改成早上比較專心」 |
| 排鬆一點 | 「每天最多 2 段專注時間」「多留一點空白」 |
| 改每週確認時間 | 「每週確認改到週六早上」 |
| 改每日檢查次數 | 「每天檢查改成三次：早上、中午、晚上」 |
| 先問再改 | 「改日曆前先問我」：週中的變動會先傳給你看，你同意才改 |
| 改頁面語言 | 「頁面改成英文」 |
| 新增例行事項 | 「每 6 週剪一次頭髮，提前一週提醒我預約」 |

改完的設定會出現在頁面的「規則」分頁。

### 使用額度

付費方案的用量有每 5 小時和每週兩種上限。排程任務要讀頁面、排行程、寫日曆，比一般問答用得多。

- **每日檢查預設 1 次。** 沒有新留言時很快就結束，但仍會用到一點額度。想要反應更快再加到 2–3 次。
- 額度快用完時，先把每日檢查減回 1 次，重要的變動直接在對話裡說。
- 額度用完時任務可能無法完成，下一次執行時會接著處理還沒處理的留言。

參考：[How do usage and length limits work](https://support.claude.com/en/articles/11647753-how-do-usage-and-length-limits-work)。

## 12. 疑難排解

**週日沒有收到下週草稿**
1. 左側欄 **Scheduled** 找到每週確認任務，看最近一次執行紀錄。
2. 如果停在等待核准，照第 7 章打開 **Automatically approve**。
3. 如果任務被暫停，恢復它。
4. 等不及的話，直接開對話說「排下週」。

**每日檢查好像沒有反應**
沒有新留言、也沒有提前完成的事時，每日檢查不會傳訊息，這是正常的。留言狀態還是「待處理」，才表示還沒處理；可以在 Scheduled 手動執行一次。

**日曆上沒有出現行程**
1. 確認 Customize → Connectors 裡 Google Calendar 是 Connected。
2. 確認看的是同一個 Google 帳號的日曆。
3. 行程狀態是「草稿，待你確認」時，還沒寫進日曆，回覆確認即可。
4. 跟 Claude 說「把本週行程重新同步到日曆」。

**頁面顯示「這個檢視無法讀取資料，請在 claude.ai 開啟」**
你打開的是預覽或沒登入的版本。用瀏覽器到 claude.ai 登入後再打開連結；主畫面網頁 App 的話，在裡面重新登入一次。

**全天活動顯示在前一天**
跟 Claude 說「檢查日曆上全天截止日的日期」，它會修正。

**一直跳出「允許」**
- 對話中：跳出提示時選 **Always allow**，每個工具只要按一次。
- 連接器：照第 5 章把 Google Calendar 的 Tool permissions 設成 Always allow。
- 排程任務：打開 Automatically approve。

**時間顯示不對**
頁面照你設定的時區顯示，不看裝置時區。出國或搬家時說「我的時區改成 Asia/Tokyo」。

**排得太滿或太鬆**
每週確認時回答「偏多」或「偏少」，下次估時會調整約兩成。也可以直接改上限（第 11 章）。

**Claude 排錯或讀錯日期**
直接告訴它哪裡錯，它會改頁面和日曆。重要的截止日請以學校或官方公告為準。

問題還是沒解決，歡迎到 GitHub 開 Issue，附上方案、使用的平台（網頁、桌面、手機）和看到的錯誤訊息，**不要貼上個人行程或頁面連結**。

## 13. 更新、停用與移除

### 更新到新版

1. 下載新版 zip，在 Customize → Skills 刪掉舊的，再上傳新的。
2. 跟 Claude 說「更新我的週行程頁面」。它會讀你現在的頁面，換成新範本，保留你改過的標題和顏色。資料存在頁面的資料庫裡，不會遺失。

每一版改了什麼，請看 [CHANGELOG](../CHANGELOG.md)。

### 停用與移除

跟 Claude 說你要做到哪一步，它會先列出要做的事請你確認：

- **暫停自動檢查：**「暫停週行程的排程任務」。之後說「恢復」就會再開。
- **清掉日曆上的行程：**「刪掉 Claude 排的日曆行程」。只會刪說明欄有「[Claude安排]」標記的活動，預設只刪今天以後的。
- **刪除頁面：**「刪除我的週行程頁面」。這一步無法復原。
- **移除 skill：** 在 Customize → Skills 關閉或刪除。
- **中斷日曆連接：** Customize → Connectors → Google Calendar → Disconnect。

## 14. 常見問題

**每週都要自己打開對話嗎？** 付費方案不用，排程任務會自動傳通知給你，點開回覆就好。免費方案要自己開對話說「排下週」。

**它會記得之前排好的事嗎？** 會。資料存在你的週行程頁面，每次排程都會先讀取，不靠對話記憶。

**會亂動我自己建的日曆行程嗎？** 不會。它只修改說明欄有「[Claude安排]」標記的活動（英文版是「[Planned by Claude]」）。

**可以用 Outlook 或只用 Apple 行事曆嗎？** 目前只支援寫入 Google 日曆。其他日曆的使用者可以只用頁面，或申請一個 Google 帳號專門放行程，再加進 Apple 行事曆。

**不是學生也能用嗎？** 可以。沒有設定學期，頁面就不會顯示學期週次；課表可以換成班表或固定會議。

**住在有夏令時間的地方呢？** 沒問題。頁面和日曆都依你設定的時區（例如 `America/New_York`）自動換算。

**可以兩個人共用一個頁面嗎？** 這個 skill 是為個人設計的，每個人請各自設定自己的頁面。
